## Method note

- `dataset_doi` verified against the DataCite REST API (`api.datacite.org/dois/{doi}`); `publication_doi` verified against the Crossref REST API (`api.crossref.org/works/{doi}`).
- Title match computed as token-overlap between the declared title and the title returned by the API (threshold 0.5); all matches came back at or near 1.0 except record 36, which failed to resolve entirely.
- Duplicate check performed as a literal DOI-string search inside `corpus/bib/references.bib` and `gg/regression_article.bib`.
- `matches_search_bib_objective` and `recommended_action` are a manual read of each record's title/venue/subjects against the scientific scope and priority domains stated in `tools/search_bib.md`; this judgment step is not machine-verifiable and should be spot-checked by a human before any record is dropped or promoted.
- Original files (`datacite_spatial_dataset_candidates.json` / `.csv`) were not modified. This report and the raw per-record API responses are separate artifacts under `data/manifests/papers/`.
